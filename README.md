# Lingora — free, AI-powered language learning

Lingora is a Duolingo-style language learning web app where **every lesson, story, review and conversation is generated by Claude**, personalised to each learner, and grounded in second-language-acquisition research. Every feature is free: no subscriptions, no paywalls, no ads.

## Features

**Personalised by AI**
- Sign-up questionnaire: target and native language, other languages you speak, age group, goals, level (or an **AI placement test**), interests, learning styles, challenges, correction preference, daily goal, and free-text notes for your tutor.
- Claude designs a **personal course path** (units → lessons with CEFR "can-do" goals), and can extend it with 6 more units whenever you finish.
- **62 languages**, including English, Spanish, French, German, Hebrew, Mandarin, Cantonese, Japanese, Korean, Arabic, Hindi, Russian, Swahili, Yiddish, Latin, Hawaiian and more. Native scripts, right-to-left support, romanization and browser text-to-speech.

**Learning**
- Learning path with units, lessons, stories, unit reviews (trophies) and **Legendary** challenges.
- **Jump ahead**: test out of units with an AI-generated test.
- 9 exercise types: new-word cards, multiple choice, word-bank sentence building, typed translation, listen-and-type, listen-and-choose, match pairs, fill-in-the-blank and speaking (speech recognition).
- **AI grading** accepts any correct translation, not just one answer key.
- **Explain my answer**: get an AI explanation of any exercise and ask follow-up questions.
- **Guidebook** for every unit (key phrases with audio, plus grammar tips).
- **Stories**: interactive AI-written stories with comprehension questions, including stories on any theme you choose.
- **AI Tutor**: role-play chats with in-line corrections, reply suggestions and a voice-call mode.
- **Practice hub**: personalised practice, mistakes review, spaced-repetition word review, listening practice and speaking practice.
- **Characters** tab for non-Latin scripts (hiragana, Hangul, Hebrew, Devanagari and more).
- **My words** list showing the strength of every word you've learned.

**Engagement (all free)**
- XP, a daily goal with a reward chest, and **streaks** with a streak calendar, streak freezes and streak repair.
- **Hearts** that regenerate over time. You can earn them back through practice or turn on unlimited hearts in settings.
- **Weekly leagues** across 10 tiers, with promotion and demotion, gem rewards and a friends leaderboard.
- **Daily quests**, a monthly challenge badge, and a free double-XP boost when you finish all your quests.
- **Achievements** with levels (Wildfire, Sage, Scholar and more).
- **Gem shop** with power-ups and outfits for Glo, the mascot.
- **Profiles**, following friends, public profile pages, weekly XP chart and a proficiency score.

## Research basis

The tutor's system prompt follows these principles (see `lib/pedagogy.ts` or the in-app `/research` page for citations):

- Spaced repetition (Leitner boxes)
- Retrieval practice
- Comprehensible input (i+1, about 95–98% known words)
- Pushed output and interaction
- Corrective feedback
- High-frequency vocabulary first
- Formulaic chunks
- Interleaving and an ~85% success rate
- Dual coding
- Self-determination theory and habit formation
- CEFR can-do goals
- FSI difficulty estimates

## Running it

```bash
npm install
cp .env.example .env.local   # then add your ANTHROPIC_API_KEY
npm run dev                  # http://localhost:3000
```

Production: `npm run build && npm start`.

| Variable | Purpose |
|---|---|
| `ANTHROPIC_API_KEY` | Required. Used only on the server. |
| `CLAUDE_MODEL` | Optional. Defaults to `claude-opus-5-5`. |
| `SESSION_SECRET` | Optional. Signs login cookies. If unset, a random secret is generated and stored. |
| `AI_DAILY_LIMIT` | Optional. Max AI requests per learner per day (default 200, `0` = unlimited). |
| `DATA_DIR` | Optional. Where the SQLite database is stored (default `./data`). |

### Costs

Because the app is free for learners, the host pays for Claude API usage. To keep that predictable:

- Each lesson is one Claude request. Lessons run at `low` effort and course planning at `medium`.
- The research and learner-profile system prompt is cached between requests.
- Guidebooks and alphabet charts are generated once and stored.
- Answers are checked locally first. Claude is only asked about typed translations that don't match an accepted answer.
- Each learner has a daily AI request limit (`AI_DAILY_LIMIT`). Learners who reach it get a friendly message, and it resets at midnight UTC.

## Try it without a server (hosted version)

`npm run build:hosted` builds the same interface as one self-contained page, `artifact-dist/lingora.html`, which can be published as a Claude artifact:

- It needs no API key. AI calls go through the artifact runtime's `sample` capability, so each learner uses their own Claude account.
- `artifact/backend.ts` runs the same routes in the browser, reusing the game engine, prompts and grading. Accounts and progress are saved in that browser only.
- Leagues and friends only include accounts created in the same browser.
- Speaking exercises are turned off, because hosted pages can't use the microphone.

The code lives in `artifact/`. Vite swaps the server-only modules and the Next.js navigation for in-browser versions, and nothing in the Next.js app changes.

## Architecture

- **Next.js (App Router) + TypeScript + Tailwind.** All pages are in `app/`; shared UI is in `components/`.
- **Claude integration** (`lib/server/claude.ts`, `lib/server/ai.ts`): every AI call uses the official `@anthropic-ai/sdk` with **structured outputs**, defined as Zod schemas, so the UI always receives well-formed lessons, stories and so on. It also enables the server-side refusal fallback (`fallbacks: "default"`) and prompt caching.
- **Game engine** (`lib/game.ts`): XP, streaks, hearts, quests, leagues, achievements, the shop and spaced repetition. These are pure functions, and all state changes are applied on the server through `/api/action`.
- **Storage** (`lib/server/db.ts`): SQLite via `better-sqlite3`, in WAL mode.
  - Each learner's game state is a JSON document. The columns needed for login, leagues, league history and friends are stored and indexed alongside it.
  - Every write runs in an `IMMEDIATE` transaction, so simultaneous requests never overwrite each other.
  - Passwords are hashed with scrypt, and logins use HMAC-signed cookies.
  - Several server processes on one machine can share the database file. To run across several machines, port this one module to Postgres.
- **Cheat-resistant progress** (`lib/server/grading.ts`, `/api/lesson/check`):
  - Every generated lesson and story is stored on the server as a one-time session. The browser never receives the answer key for exercises the server grades.
  - The server grades each answer, records the first attempt and charges hearts itself.
  - When a lesson ends, the server computes the result from its own records: correct answers, pass/fail, new words, mistakes and XP. The browser can't submit made-up scores, and each session can only be submitted once.
  - Combo bonuses are capped by the number of correct answers, and time is capped by how long the server has seen the session.
  - Pair matching and speech recognition happen in the browser, so those two exercise types are self-reported.
- **Audio**: the browser's speech synthesis needs an installed voice for each language.
  - The app checks this on every device. If there's no voice, listening and speaking exercises are left out of lessons (the server enforces this too) and the learner sees a notice explaining how to add one.
  - Speech recognition needs Chrome or Edge.
